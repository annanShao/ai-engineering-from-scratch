个人学习笔记,跟随 `phases/` 课程推进。

## 结构约定

```
learning-notes/
├── README.md                              # 本文件
└── phase-<NN>-<phase-name>/
    └── <NN>-<lesson-name>.md              # 一节课一篇
```

每篇 lesson 笔记四段式:
1. **课程坐标** —— 路径、时长、前置、关键文件
2. **核心金句** —— 这节课沉淀的 1~N 条 takeaway
3. **关键概念地图** —— 概念之间的关系、对比表
4. **手做记录** —— exercise 改了什么、跑出什么、踩了什么坑
